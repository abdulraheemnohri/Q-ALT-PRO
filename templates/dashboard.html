Q-ALT PRO Guide

Command Console

Type commands directly into the console input:

  • /run - Execute current configuration
  • /clear - Clear console output
  • /clearlogs - Delete all stored logs
  • /addnode [url] - Connect a new node
  • /importnodes [url1,url2] - Bulk import nodes
  • /reset - Reset dashboard state
  • /help - Show available commands
